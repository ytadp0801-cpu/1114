かえでさん向け誕生日サプライズページ

内容：
- index.html：ページ本体
- cover.gif：最初に表示する封筒の画像
- message.gif：開いた後の誕生日メッセージ画像
- happy-birthday-334876.mp3：BGM

【公開方法】
1. ZIPを解凍します。
2. GitHubで新しいPublicリポジトリを作ります（例：kaede-birthday）。
3. Add file → Upload files から、この4ファイルをすべてアップロードします。
4. Commit changes を押します。
5. Settings → Pages を開き、Deploy from a branch、Branch: main、Folder: /(root) を選んで Save。
6. 数分待ち、Pagesに表示されたURLを開いてテストします。
7. そのURLをLINEなどで送れます。QRコードも公開URLができてから作ってください。

注意：
- 4つのファイルは同じフォルダ（リポジトリの一番上）に置いてください。
- 最初の封筒画像をタップするとメッセージが表示され、BGM再生を試みます。
- スマホのブラウザや消音設定によっては、音が出ない場合があります。
- メッセージ画像に「やぎ」と書かれているので、送り主を変えたい場合は message.gif の画像自体を編集してください。
